# Assignment 13: Reduce, Some, Every And Map

## Experiment Title
Reduce, Some, Every and Map

## Aim
Use reduce, some, every and map with arrays while preserving the original array.

## Software / Tools Required
Visual Studio Code or any text editor, a modern web browser (for browser-based tasks), and Node.js (for .js programs).

## Theory
reduce() combines array elements into one accumulated value. some() checks whether at least one element satisfies a condition. every() checks whether all elements satisfy a condition. map() creates a new array by transforming each element and leaves the original array unchanged.
