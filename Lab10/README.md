# Assignment 10: Objects And Destructuring

## Experiment Title
Objects and Destructuring

## Aim
Create and update object properties, and extract values from arrays and objects using destructuring.

## Software / Tools Required
Visual Studio Code or any text editor, a modern web browser (for browser-based tasks), and Node.js (for .js programs).

## Theory
An object stores related information as key-value pairs. Properties can be read and updated using dot notation. Destructuring is syntax that extracts values from arrays or properties from objects into variables. Array destructuring follows position, while object destructuring uses property names.
