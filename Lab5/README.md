# Assignment 5: Arrays, Array Methods And Nested Arrays

## Experiment Title
Arrays, Array Methods and Nested Arrays

## Aim
Create arrays, access their items, use forEach and filter, and read a value from a nested array.

## Software / Tools Required
Visual Studio Code or any text editor, a modern web browser (for browser-based tasks), and Node.js (for .js programs).

## Theory
An array stores multiple values in an ordered collection. Array indexes start at zero and the length property gives the number of elements. forEach() executes a callback for each element. filter() creates a new array containing elements that pass a condition. A nested array is an array stored inside another array and can be accessed using multiple indexes.
