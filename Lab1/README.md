# Assignment 1: Your First Javascript Script

## Experiment Title
Your First JavaScript Script

## Aim
Run JavaScript in a browser and with Node.js, and declare values using const and let.

## Software / Tools Required
Visual Studio Code or any text editor, a modern web browser (for browser-based tasks), and Node.js (for .js programs).

## Theory
JavaScript is a programming language used to add behaviour to web pages and can also run outside the browser using Node.js. A script can be placed in an HTML script element or saved in a .js file. const declares a binding that cannot be reassigned, while let declares a block-scoped variable that can be reassigned. console.log() prints values to the developer console or terminal. The typeof operator reports the data type of a value.
