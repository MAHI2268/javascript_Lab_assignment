# Assignment 4: Writing Functions

## Experiment Title
Writing Functions

## Aim
Create functions with return values, arrow-function syntax and default parameters.

## Software / Tools Required
Visual Studio Code or any text editor, a modern web browser (for browser-based tasks), and Node.js (for .js programs).

## Theory
A function is a reusable block of code that performs a task. Parameters receive input values and return sends a result back to the caller. Arrow functions provide a shorter function syntax. A default parameter supplies a value when the caller omits that argument or passes undefined.
