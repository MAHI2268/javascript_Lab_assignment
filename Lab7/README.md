# Assignment 7: Constructor Functions And Classes

## Experiment Title
Constructor Functions and Classes

## Aim
Create objects using a constructor function and an ES6 class, and add a method through the prototype.

## Software / Tools Required
Visual Studio Code or any text editor, a modern web browser (for browser-based tasks), and Node.js (for .js programs).

## Theory
A constructor function initializes properties on objects created with new. A class provides a structured syntax for defining constructors and methods. The prototype is an object from which instances can share methods, avoiding the need to create a separate copy of the method for every instance.
