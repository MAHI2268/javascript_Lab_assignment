# Assignment 3: Conditions And Loops

## Experiment Title
Conditions and Loops

## Aim
Use if, else if and else for decisions, and for and while loops for repetition.

## Software / Tools Required
Visual Studio Code or any text editor, a modern web browser (for browser-based tasks), and Node.js (for .js programs).

## Theory
Conditional statements execute different blocks depending on whether a condition is true or false. A for loop is useful when the number of repetitions is known. A while loop repeats as long as its condition remains true. Updating the loop variable or accumulated value is essential to ensure that a loop eventually stops.
